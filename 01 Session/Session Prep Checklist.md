> [!lore] Work top to bottom. Everything above the line is what actually matters at the table.

## The Week Before

- [ ] Read the module end to end, once, without taking notes
- [ ] Read it again, filling [[Run Sheet]] as you go
- [ ] Fill the three **Turning Points** on the Run Sheet — these are the only things you must know cold
- [ ] Write read-aloud text for the areas you're sure they'll hit
- [ ] Decide the **escape clock** and what happens if it runs out
- [ ] Fill in [[04 NPCs]] — voice and mannerism for each, one line is enough
- [ ] Check [[05 Bestiary]] statblocks all render
- [ ] Pre-roll or pre-plan the ritual chamber fight

## The Day Before

- [ ] Get the five [[Party Overview|PC sheets]] filled in, or at least AC / HP / passive Perception
- [ ] Note the party's highest passive Perception — you'll need it constantly
- [ ] Set marching order
- [ ] Agree lines and veils with the table (this module earns it)
- [ ] Build encounters in [[Initiative & Combat]]
- [ ] Test every map opens: [[Death House (Map Hub)]]

## An Hour Before

- [ ] Music queued — see [[Atmosphere & Pacing]]
- [ ] Lighting set
- [ ] Dice, minis, tokens out
- [ ] Snacks and water on the table
- [ ] Phones face down
- [ ] Open [[Run Sheet]] on one screen, [[Death House (Map Hub)]] on the other

---

## At the Table

- [ ] Say the safety tools out loud before the cold open
- [ ] Start on time
- [ ] Take a break at the 2-hour mark, whatever is happening

## After

- [ ] Dump everything into [[Session Notes]] while it's fresh
- [ ] Note what dragged and what landed
